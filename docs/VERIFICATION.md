## 真机验收步骤

1. 执行连接脚本，手机点开始，确认 Mac 光标跟随单指移动。
2. 在无敏感内容的测试窗口验证左键、双击、右键、双指水平/垂直滚动和长按拖动。
3. 进入纯黑模式，确认屏幕无可见内容、触摸仍工作；同时确认用户是否接受该方案。
4. 按手机电源键，确认控制停止；解锁后须重新点击开始。拖动或按 Option 时拔线，确认两秒左右内释放。
5. 先验证 Mac 实体 Option 唤起豆包；若启用手机音量上键映射，再确认合成 Option 是否有效。语音仍使用 Mac 麦克风。

## 0.2.0 蓝牙验收

1. 拒绝附近设备后应仍能选 USB；允许后才能读取已配对设备和建立 HID 连接。
2. 选择已有 Mac 或限时可发现，在 Mac 设置完成配对；未连通点击纯黑模式不应黑一下又退回。
3. 连通后拔下 USB，验证单指移动、左右键、水平/垂直双指滚动、长按拖动和音量上键右 Option。
4. 纯黑模式连续使用；按电源、返回、切后台各自停止。解锁不自动控制。持有拖动/Option 时断线，检查 Mac 无残留按键。
5. 取消系统蓝牙提示、权限被撤销、蓝牙关闭、连接超时各自显示可理解的原因，不能反复弹权限框。

以上步骤尚未完成真机验收，报文测试不能代替实际配对和体验测试。
