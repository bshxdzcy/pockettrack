## 真机验收步骤

1. 执行连接脚本，手机点开始，确认 Mac 光标跟随单指移动。
2. 在无敏感内容的测试窗口验证左键、双击、右键、双指水平/垂直滚动和长按拖动。
3. 进入纯黑模式，确认屏幕无可见内容、触摸仍工作；同时确认用户是否接受该方案。
4. 按手机电源键，确认控制停止；解锁后须重新点击开始。拖动或按 Option 时拔线，确认两秒左右内释放。
5. 先验证 Mac 实体 Option 唤起豆包；若启用手机音量上键映射，再确认合成 Option 是否有效。语音仍使用 Mac 麦克风。
